Front-end

What visitors and the admin can see and use today.
Framework: Next.js 15 Status: Live

01 Public Site

Every public page is live: Bio, Research, Publications, Research Groups, Upcoming Events, and Make Appointment. Each one is server-rendered and cached, so pages load fast without a database round trip on every visit.

PageWhat it doesStatus
Make Appointment A quick bot check, then the embedded Calendly widget for picking an open slot. Matches light/dark theme and resizes to fit the full calendar. Live
Bio / Research / Publications / Research Groups / Upcoming Events All content-driven, editable from the admin dashboard. Live
Theming Light, dark, or system, applied site-wide. Live

02 Admin Area

Login, dashboard, and CRUD screens for research, publications, research groups, team members, appointments, and settings are all live. There's a single admin account, no public sign-up.

03 Stack

Next.js 15, React 19, Tailwind CSS v4, shadcn/ui components, next-themes. Forms use React Hook Form with the same validation rules as the server, so what a visitor sees matches what actually gets accepted. There is no translation layer; the site is English-only by design.
